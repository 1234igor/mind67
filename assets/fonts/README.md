# Fonts

**Lilex Regular** (`Lilex-Regular.ttf`) — [SIL Open Font License 1.1](OFL.txt).
Upstream: <https://github.com/mishamyrt/Lilex> (v2.700).

This is the family GPUI maps Zed's code font to (`.ZedMono` / `Zed Plex Mono`
→ Lilex). It is compiled into the binary, so the app needs nothing installed;
`brew install --cask font-lilex` puts it on the system as well.
